# PWA

Приложение устанавливается с HTTPS-сайта через меню браузера или кнопку
«Установить приложение», когда браузер поддерживает предложение установки.
На iPhone: «Поделиться» → «На экран Домой». Для локальной проверки подходит localhost.

Начальная страница — `/`. Клиент и сотрудник используют существующие вход и кабинеты.
Установка не меняет права доступа. Админка тоже открывается в установленном приложении.

Без интернета показывается отдельная страница. Service worker хранит только
`/offline/`, без cookies; страницы кабинетов, API, фотографии и POST-запросы
не кэшируются и не отправляются повторно автоматически. После сбоя при сохранении
пользователю следует проверить результат на сервере перед повторной отправкой.
Push-уведомления и работа с записями без интернета в эту версию не входят.

Для оператора и владельца непрочитанные уведомления также передаются в
`navigator.setAppBadge`. При нулевом счётчике или выходе значок очищается.
Используется существующий опрос каждые 20 секунд, а также обновление при возврате
в окно и восстановлении сети. Фоновые таймеры могут задерживаться браузером.
При полностью закрытом приложении новые значения не поступают: для этого нужен Push.
Отображение числа зависит от браузера и ОС; целевой вариант — установленная PWA
в Chrome/Edge на Windows с разрешёнными значками панели задач. При отсутствии
поддержки или запрете API колокольчик продолжает работать.
Документация: https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/How_to/Display_badge_on_app_icon

Worker доступен по `/service-worker.js`, с областью `/` и `Cache-Control: no-cache`.
Новая версия worker активируется после закрытия старых вкладок приложения;
принудительной перезагрузки заполненных форм нет. При изменении offline-страницы
нужно увеличить версию `sto-pwa-offline-v1` в шаблоне worker.
Удаляются только старые кэши с этим префиксом.

Проверки: `node --test scripts/test_pwa_worker.cjs` и
`python manage.py test booking.tests.test_pwa`.
В браузере проверить установку, перезапуск, выход, переход без сети и возврат онлайн.
В DevTools → Application → Cache Storage должна быть только offline-страница.

Изменения публикуются только в `codex/production-hardening-ready` до отдельного
разрешения на слияние в `main`. Для VDS собрать образ заново; новых миграций нет.
